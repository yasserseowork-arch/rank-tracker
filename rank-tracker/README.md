# SEO Kw Tracker

© 2026 SEO Kw Tracker. جميع الحقوق محفوظة.
By: Muhammed Yasser المستهدف — Saudi Rank Tracker (Chrome MV3)

أتمتة كاملة لمهمة تتبع الترتيب (Rank Tracking) في جوجل المنطقة المستهدفة للمتاجر الإلكترونية،
بدون أي API خارجي وبدون خادم وسيط — كل شيء يعمل محلياً داخل متصفحك.

> الإضافة تقرأ SERP الحقيقي بعين المتصفح (100 نتيجة)، تمرر بشرياً، تتعاون مع إضافة
> **Buster** لحل الكابتشا الصوتية، وتُخرج الترتيب جاهزاً للصق في شيتك.

---

## 1) ماذا تفعل الإضافة بالضبط؟

1. تأخذ الكلمات المفتاحية من: لصق مباشر / ملف CSV / رابط شيت جوجل مشارك.
2. قبل كل كلمة: **مهلة بشرية افتراضية 4 ثوانٍ** (+ تذبذب عشوائي) احتراماً لقواعد جوجل.
3. تفتح `google.com/search?q=…&gl=<region>&hl=ar&num=100&pws=0`
   — الاستهداف الجغرافي للسعودية عبر معاملات جوجل نفسها، **بدون VPN**.
   ومن الكلمة الثانية فصاعداً: **نفس التبويب** تماماً — تُكتب الكلمة في صندوق
   البحث ويُرسَل النموذج كما يفعل البشر.
4. تنتظر تحميل النتائج بذكاء: **مسح دوري** للصفحة كل ~1.8 ثانية (مثل Ctrl+F متكرر)
   ينتظر دفعات الأداة المساعدة (~10 نتائج في كل دفعة)، وثبات العدّاد ~7 ثوانٍ = انتهى التحميل.
5. **خروج مبكر**: أول ما يظهر موقعك — عضوياً أو داخل **AI Overview** — تُرسل النتيجة
   (والمسح بقى «واعياً بالتقدّم»: طول ما النتائج الجديدة بتنزل كمّل لحد 100 حتى لو
   تجاوزت الـ20 ثانية، وعند التوقف بيكمّل الدفعات الجاية بجلب خلفي — المراكز #30+ مضمونة)
   فوراً وينتقل للكلمة التالية بدون انتظار باقي الـ100 نتيجة.
6. تستبعد الإعلانات و"People also ask"، وتحسب الترتيب العضوي فقط،
   وترصد ظهور الموقع في AI Overview بترتيب بصيغة "2 AI".
7. تطابق موقعك بالدومين (مع النطاقات الفرعية) أو باسمه — عربي أو إنجليزي — بعد التطبيع، أو الاثنين معًا؛ أي اسم من الاثنين لو اتلاشى يعتبر ظهور.
8. إن ظهر `/sorry/` (كابتشا): تكشفها بثلاث طرق (إعلان دوري، مسبار رابط، مسبار إطارات)،
   ثم تقود الدورة ذاتياً: checkbox → تحدي صوتي → زر Buster → عند الفشل:
   **⟳ تحدي جديد + Buster مجدداً** حتى الحل أو الاستنفاد (إيقاف مؤقت + استئناف يدوي/تلقائي).
9. **صفحات الخطأ تُعالَج وحدها**: 500/502/مشكلة وصول/انقطاع شبكة → ريفرش تلقائي
   حتى مرتين (عدّاد يبقى بعد الريفرش)، وريفرش أخير من المحرك إن لزم.
10. **سقف فحوصات يومي** (افتراضي 150) حمايةً لنطاقك من قواعد جوجل الصارمة.
11. تسجل الترتيب في جدول النتائج + تاريخ لكل كلمة + منحنى بياني،
   وتصدّر CSV أو تنسخ TSV للصق المباشر في الشيت.

## 2) التثبيت (وضع المطور)

1. افتح `chrome://extensions`
2. فعّل **Developer mode / وضع المطور** (أعلى اليمين).
3. اضغط **Load unpacked / تحميل غير مضغوط** واختر مجلد `rank-tracker`.
4. (من 1.18.9) ثبّت إضافة [Buster](https://chromewebstore.google.com/detail/buster-captcha-solver-for/hddnkoimebgkeflboejfjmnkbohjgkhh) كإضافة مستقلة — لم تعد مدمجة داخل هذه الأداة؛ الأداة تكتفي بالضغط على زرارها البرتقالي وتكمل بحلها الصوتي المحلي لو لزم.
5. اضغط أيقونة الإضافة → تفتح **اللوحة الجانبية**.

### 2.1) عزل تام عن بروفايلاتك التانية (اختياري لكن أنصح بيه)
من 1.19.2 كل تبويبات الفحص بتفتح لوحدها في **نافذة الأداة الخلفية** (مفيش شد فوكس،
والـ debug banner بيرقص جوه النافذة دي بس). لو فتحِت البروفايل التاني من نفس instance
كروم («New window with different profile») فالبانر ممكن يلمع ثانية فوق أي نافذة لأن
العملية مشتركة — للعزل الحقيقي شغّل بروفيل التراكينج بإنستانس منفصل:

```
chrome.exe --user-data-dir="%LOCALAPPDATA%\ChromeTracking" --no-first-run     (Windows)
google-chrome --user-data-dir=$HOME/.chrome-tracking                           (Linux)
```

## 3) الإعداد الأول (دقيقتان)

| الحقل | القيمة المقترحة |
|---|---|
| دومين الموقع | `mystore.com.sa` |
| اسم الموقع بالعربي | `متجري` (اختياري — احتياطي للمطابقة النصية) |
| اسم الموقع بالإنجليزي | `My Store` (اختياري — بيشارك في نفس المطابقة) |
| نمط المطابقة | الدومين أو الاسم |
| gl / hl | `sa` / `ar` |
| عدد النتائج | `100` |
| مهلة قبل كل كلمة | `4000` ملي ثانية |

ثم الصق كلماتك (سطر لكل كلمة أو عمود كامل من الشيت) → **＋ إضافة الكلمات** → **▶ بدء الفحص**.

## 4) دورة الكلمة المفتاحية (State Machine)

```
pending → running → (delay 4s±jitter) → tab open → complete
   ├─ SERP parsed ──► match ──► result saved ──► done ──► tab close ──► next
   └─ /sorry/ captcha ──► run=captcha
          ├─ Buster attempt 1..N
          │     ├─ solved (URL left /sorry/) ──► SERP parsed ──► …
          │     └─ timeout ──► reload(new challenge) + Buster ──► retry
          └─ all failed ──► paused(captcha-failed)
                 ├─ manual solve detected ──► auto resume
                 └─ user resume ──► skip keyword
```

## 7) أسئلة شائعة

- **لماذا لا أحتاج VPN؟** لأن `gl=<region>&hl=ar` يجبران جوجل على إظهار نتائج منطقة المنطقة المستهدفة
  ولغة عربية. الـ VPN يبقى مفيداً فقط إن أردت إخفاء عنوان IP نفسه.
- **الكابتشا تظهر كثيراً؟** قلل عدد الكلمات في الجلسة، وزد `cooldownEvery`،
  وافصل الجلسات. الإضافة تطبق مهلاً وتذبذباً واستراحات لتقليل الاستفزاز.
- **Buster فشل (Wit.ai could not detect…)**؟ الإضافة تضغط تحدي جديد وتعيد تلقائياً
  حتى N محاولات؛ وبعدها توقف مؤقتاً وتنتظر حلك اليدوي مع استئناف تلقائي.
  يمكنك من إعدادات Buster切换 الخدمة إلى IBM Watson لموثوقية أعلى.
- **الشيت لا يُجلب بالرابط؟** اجعل المشاركة "أي شخص لديه الرابط"، أو استخدم اللصق/CSV،
  أو صدّر CSV من الإضافة والصقه فوق نتائجك.
- **أين تُكتب النتائج في الشيت؟** زر "نسخ للصق في الشيت" ينسخ عمودين (الكلمة، الترتيب)
  بصيغة TSV تلصق مباشرة في نطاق الشيت المقابل دون كسر التنسيق.

## 8) إخلاء مسؤولية

هذه أداة فحص ترتيب لأغراض تحسين محركات البحث الخاصة بموقعك. الالتزام بشروط خدمة جوجل
مسؤوليتك: الإضافة تطبق إيقاعاً بشرياً محافظاً (مهلة 4 ثوانٍ + تذبذب + استراحات) لتقليل
أي ضغط غير طبيعي، ولا تتجاوز أي كابتشا بنفسها — الحل يتم عبر إضافة Buster المثبتة لديك
أو يدوياً بواسطتك.
