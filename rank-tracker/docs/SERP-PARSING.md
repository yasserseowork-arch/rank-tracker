# SERP Parsing — قراءة 100 نتيجة بترتيب صحيح

## الرابط المُولّد

```
https://www.google.com/search?q={keyword}&gl=<region>&hl=ar&num=100&pws=0&ie=utf-8
```

- `gl=<region>` : منطقة النتائج = المنطقة المستهدفة (بديل نظامي عن VPN).
- `hl=ar` : لغة الواجهة والنتائج.
- `num=100`: أقصى عدد نتائج في صفحة واحدة → الترتيب حتى #100 بدون ترقيم صفحات.
- `pws=0` : تعطيل التخصيص الشخصي قدر الإمكان.

## خوارزمية الانتظار والتمرير (Scroll-Settle)

```
1) waitFor(أول نتيجة عضوية أو علامة "لا نتائج")   ≤ min(maxWait, 20s)
2) loop حتى maxWaitResultsMs:
     إن لم نبلغ القاع: scrollBy(500..1000px) + dispatchEvent('scroll')
     وإلا: علّم reachedBottomOnce
     sleep(scrollStepMs ± 0..180ms)
     count = organicCount()
     إن count ≥ num            → stableSince = now
     وإن count تغيّر            → stableSince = null
     وإن count ثابت والقاع مرة واحدة على الأقل → stableSince ||= now
     إن stableSince مضى عليه ≥ settleMs والقاع مُبلغ → خروج
3) scrollTo(0) ثم collect()
```

التمرير التدريجي ضروري لأن جوجل تحمّل كتل نتائج إضافية عند الاقتراب من القاع
(lazy rendering)، والقراءة المبكرة تعطي ترتيباً ناقصاً.

## استخلاص النتائج العضوية (مقاوم لتغييرات جوجل — درس Serp Counter)

```
الثابت الوحيد في SERP عبر كل تصميمات جوجل: <a href="http…"><h3>…</h3></a>
لذلك:
  anchors = #search/#rso/main a[href^=http]  (تراجع: كل a بالصفحة)
  لكل رابط: يحتوي h3 ؟ ظاهر (rect ≥ 8px) ؟ ليس إعلاناً/‏PAA/رابط جوجل داخلي؟
  الترتيب = ترتيب المستند (1-based) — لا اعتماد على div.g أو .yuRUbf إطلاقاً
  البلوك الأقرب (div.g/data-hveid/.yuRUbf) يُستخدم للـ snippet فقط
```

## الجلب الذاتي الخلفي (self-fetch)

إن استقرت الصفحة دون بلوغ `num` (ولا توجد أداة عدّاد تمدّها):
`fetch(نفس الرابط + start=10,20,…)` بنفس الجلسة، parse بـ DOMParser،
دمج فريد بالرابط، بحث مبكر بعد كل دفعة، حتى 100 نتيجة أو كابتشا/فشل.
لا تنقّل للتبويب إطلاقاً — الصفحة الأولى تبقى كما هي.

## المطابقة (في الـ Service Worker، دوال نقية مُختبرة)

- **دومين**: تطبيع المضيف (حذف www/m/shop/store) ثم مطابقة كاملة أو لاحقة
  `.domain` أو مقارنة النطاق القابل للتسجيل (آخر جزأين/ثلاثة مع com.sa وأخواتها).
- **اسم**: تطبيع عربي (إزالة تشكيل وتطريز، توحيد أ/ى/ة، أرقام هندية→عربية)
  ثم احتواء، مع مطابقة مرنة تحذف كلمة "متجر/محل/store/shop" من اسم المتجر.
- **both**: أي منهما أولاً بأول حسب ترتيب النتائج.

## ماذا يُسجَّل لكل فحص؟

`keyword, found, position, url, title, total, adsCount, noResults, via, serpUrl, checkedAt`
— كافٍ لإعادة لصقه في الشيت أو لبناء تقارير تاريخية لكل كلمة (`history[]`).
